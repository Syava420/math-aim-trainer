# Math Aim Trainer 🎯⚡

**Киберспортивный аим-тренер для таблицы умножения.**
Вдохновлен соревновательными шутерами и режимом Gridshot в Aim Lab / KovaaK's. Вместо скучного заучивания чисел — динамичный отстрел мишеней на скорость реакции, флики мыши и комбо-стрики.

---

## 🚀 Возможности

- **3 Режима игры**:
  - **Gridshot 60s**: классический минутный соревновательный раунд на максимум очков и точности.
  - **Блиц 30s**: турбо-раунд на максимальную концентрацию и скорость.
  - **Свободный тир**: игра без таймера для комфортного запоминания.
- **Умные ложные мишени (Distractors)**: игра подставляет не случайные числа, а близкие и коварные ответы (например, `54` против `56`, `42` против `48`), тренируя реальное различение.
- **Система стрельбы & Juice**:
  - Кастомные киберспортивные прицелы (FPS Crosshair, Dot, Circle).
  - Отдача прицела (recoil kick) и хитмаркеры попаданий/промахов.
  - Процедурный синтезатор звука на **Web Audio API** (сочные щелчки, пинги, нарастающий тон комбо-стрика, без внешних mp3).
  - Канвас-эффекты: искры при попадании, ударные волны, всплывающий боевой текст (`CRIT! +150`, `+100`, `MISS`).
- **Глубокая аналитика и разбор раунда (как в Aim Lab)**:
  - Звания: **S+ (Киберспортсмен)**, **S (Мастер)**, **A (Меткий стрелок)**, **B**, **C**.
  - Метрики: Точность %, Средняя скорость реакции (мс), Попаданий в минуту (TPM), Максимальная серия.
  - **Анализ слабых мест**: список примеров, где была допущена ошибка или заминка (>1.5 сек).
  - **Кнопка «Тренировать ошибки»**: мгновенный запуск тира только с теми примерами, где ты ошибся!
- **Гибкая кастомизация**:
  - Выбор конкретных множителей (например: тренировать только сложные `6, 7, 8, 9` или только `× 7`).
  - Выбор размера мишеней (Microshot / Standart / Casual).
  - Регулировка громкости и отключение звука.

## 🛠 Запуск проекта

У проекта **нет сторонних npm-зависимостей** — он работает на чистом современном стеке (HTML5 + CSS3 + ES Modules + Canvas + Web Audio API).

### Вариант 1: Через Node.js
```bash
npm start
```
Открой браузер по адресу: `http://localhost:3000`

### Вариант 2: Запуск тестов
```bash
npm test
```

## 📂 Архитектура кода (Modular & Anti-Monolith)

```
math-aim-trainer/
├── index.html                   # Семантическая разметка (экраны Меню, Тир, Модалки)
├── server.js                    # Легковесный нативный HTTP-сервер на Node.js
├── src/
│   ├── css/
│   │   ├── base.css             # Стили темы, токены, кнопки, экран меню
│   │   ├── arena.css            # Арена, сетка, мишени, прицелы, анимации
│   │   ├── hud.css              # HUD в бою (уравнение, таймер, комбо-стрики)
│   │   └── modal.css            # Модалки результатов, рангов и настроек
│   └── js/
│       ├── app.js               # Главный координатор и переключение экранов
│       ├── core/
│       │   ├── math-engine.js   # Генерация примеров и правдоподобных дистракторов
│       │   ├── sound-engine.js  # Процедурный Web Audio API синтезатор
│       │   ├── particle-fx.js   # Canvas-партиклы, искры, всплывающий текст
│       │   └── stats-store.js   # LocalStorage, рекорды и трекер слабых мест
│       ├── game/
│       │   ├── target-manager.js # Спавн и позиционирование мишеней без наложений
│       │   └── game-controller.js# Игровой цикл, таймер, множители и очки
│       └── ui/
│           ├── crosshair.js     # Прицел с отдачей и хитмаркерами
│           ├── hud-view.js      # Отрисовка боевого интерфейса
│           ├── results-view.js  # Экран результатов, ранги и тренировка ошибок
│           └── settings-view.js # Окно настроек
└── tests/
    ├── verify-engine.test.js    # Тесты генератора примеров и фильтрации
    └── test-scoring.test.js     # Тесты подсчета очков и рангов
```
